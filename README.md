# Resume

Personal resume built with React and Tailwind CSS, bundled with Vite. Optimized for A4 print layout.

## Stack

- React 18
- Tailwind CSS 4
- Vite 5

## Getting Started

```bash
npm install
npm run dev
```

## Print

Use the browser's print function (`Ctrl+P`) to export as PDF. The layout is designed for A4 format.
